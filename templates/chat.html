About This Chatbot

This assistant helps Cate students and faculty find books quickly. Ask it for recommendations on a topic, subject, or genre, and it will search the library's own collection first, then look beyond it with a web search if nothing in-house is a good fit. It remembers context within a conversation, so you can ask follow-up questions to narrow down a suggestion.
